= Missing Semester

Курс, восполняющий пробелы в стандартных программах обучения CS.
Здесь мы разберём инструменты командной строки, которые повышают продуктивность разработчика, но редко преподаются в университетах.

Данные материалы основаны на курсе https://missing.csail.mit.edu/[Missing Semester] MIT.

== Структура курса

Курс состоит из лекций, каждая из которых посвящена конкретной теме.
Каждая лекция включает теоретический материал и практические упражнения.

== Рекомендуемые материалы

Для тех, кто чувствует себя неуверенно в командной строке:

. Книга "The Linux Command Line" Уильяма Шоттса -- подробное введение в работу с bash.
. https://tldr.sh/[tldr] -- упрощённые man-страницы с примерами использования.
. https://www.shellcheck.net/[shellcheck] -- статический анализатор shell-скриптов, помогает избегать распространённых ошибок.
