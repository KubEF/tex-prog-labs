= Язык оболочки (bash)

Предыдущий пример ввёл новое понятие: пайпы (`|`).
Большинство командной строковых программ работают со своим "стандартным вводом" (stdin), если не указан аргумент-файл.
`|` берёт "стандартный вывод" (stdout) программы и передаёт его как stdin следующей.
Это позволяет *комбинировать* программы -- и делает оболочку продуктивной средой.

На самом деле большинство оболочек реализуют полноценный язык программирования (bash), аналогичный Python или Ruby.
Есть переменные, условные конструкции, циклы и функции.

== Перенаправление (Redirections)

`>file`:: Записывает stdout программы в файл (вместо терминала).
`>>file`:: Дописывает в файл (не перезаписывает).
`<file`:: Читает данные из файла как stdin.

[,console]
----
missing:~$ echo "hello" > output.txt
missing:~$ cat output.txt
hello
----

[TIP]
====
Программа `tee` выводит stdin в stdout и одновременно записывает в файл:

[,console]
----
verbose cmd | tee verbose.log | grep CRITICAL
----
Полный лог сохраняется в файл, а в терминале видны только критические строки.
====

== Условные конструкции

[,bash]
----
if command1; then
    command2
    command3
fi
----

Выполняет `command1`, и если она успешна -- `command2` и `command3`.
Можно добавить `else`.

Для проверки условий используется команда `test` (или `[`):

[,bash]
----
# Существует ли файл?
test -f file
[ -f file ]

# Равны ли строки?
[ "$var" = "string" ]
----

В bash также есть более безопасная встроенная версия `[[ ]]`.

== Циклы

=== while

[,bash]
----
while command1; do
    command2
    command3
done
----

Повторяет тело цикла, пока `command1` не завершится с ошибкой.

=== for

[,bash]
----
for varname in a b c d; do
    command
done
----

Выполняет `command` четыре раза, каждый раз с `$varname` равным одному из значений.

Часто используют *подстановку команд*:

[,bash]
----
for i in $(seq 1 10); do
    echo "Итерация $i"
done
----

`$(seq 1 10)` выполняет команду `seq 1 10` и подставляет её вывод.
В старом коде иногда используют обратные кавычки (`` `seq 1 10` ``), но `$()` предпочтительнее -- его можно вкладывать.

== Запись скриптов

Длинные команды лучше записывать в `.sh`-файл:

[source,bash]
----
include::example$stress_test.sh[]
----

=== Shebang

Первая строка `#!/bin/bash` -- shebang.
Когда файл с таким началом исполняется, оболочка запускает программу `/bin/bash` и передаёт ей содержимое файла.
Аналогично работает shebang для Python (`#!/usr/bin/python`).

=== set -euo pipefail

Вторая строка `set -euo pipefail` делает bash "строже":

`-e`:: Выход из скрипта при ошибке любой команды.
`-u`:: Ошибка при использовании неопределённой переменной (вместо пустой строки).
`-o pipefail`:: Ошибка в любой команде пайпа приводит к ошибке всего скрипта.

== Дополнительные возможности

* Фоновые задачи: `command &` -- запуск параллельно.
* Арифметическое расширение: `$(( 2 + 2 ))`.
* Управление параметрами: `${var:-default}` -- значение по умолчанию.

[WARNING]
====
Bash имеет множество подводных камень.
Рекомендуется использовать https://www.shellcheck.net/[shellcheck] при написании скриптов.
Для сложных скриптов (100+ строк) стоит рассмотреть переход на Python.
====
