= Упражнения

Каждая лекция курса сопровождается серией упражнений.
Некоторые ставят конкретную задачу, другие -- открытые ("попробуйте использовать X и Y").
Рекомендуется не просто выполнять, а экспериментировать и задавать вопрос "почему?".

== Упражнение 1: Проверка оболочки

Для курса нужна Unix-оболочка (Bash или ZSH).

* Linux / macOS: специальных действий не требуется.
* Windows: используйте https://docs.microsoft.com/en-us/windows/wsl/[WSL] или виртуальную машину с Linux.

Проверьте свою оболочку:

[,console]
----
$ echo $SHELL
----

Если вывод -- `/bin/bash` или `/usr/bin/zsh`, всё в порядке.

== Упражнение 3: Glob-паттерны

В команде `find ~/Downloads -type f -name "*.zip" -mtime +30` конструкция `*.zip` -- это *glob*.

Создайте тестовую директорию с несколькими файлами и поэкспериментируйте:

[,console]
----
$ mkdir /tmp/test_glob && cd /tmp/test_glob
$ touch file1.txt file2.txt file3.md a.txt b.txt c.txt
$ ls *.txt
$ ls file?.txt
$ ls {a,b,c}.txt
----

Подробнее: https://www.gnu.org/software/bash/manual/html_node/Pattern-Matching.html[Pattern Matching] в руководстве bash.

== Упражнение 6: Код возврата и комбинирование

`$?` хранит код возврата последней команды (0 = успех).
`&&` запускает следующую команду только при успехе предыдущей.
`||` -- только при неудаче.

Напишите одну команду, которая создаёт `/tmp/mydir` только если она ещё не существует.

[,console]
----
$ [ -d /tmp/mydir ] || mkdir /tmp/mydir
----

Подробнее: https://www.gnu.org/software/bash/manual/html_node/Exit-Status.html[Exit Status].

== Упражнение 8: Скрипт проверки файла

Напишите скрипт, который принимает имя файла как аргумент (`$1`) и проверяет его существование с помощью `test -f` или `[ -f ... ]`.
Скрипт должен выводить разные сообщения в зависимости от того, существует ли файл.

[,console]
----
$ cat > check.sh << 'EOF'
#!/bin/bash
if [ -f "$1" ]; then
    echo "Файл '$1' существует."
else
    echo "Файл '$1' не найден."
fi
EOF
----

Подробнее: https://www.gnu.org/software/bash/manual/html_node/Bash-Conditional-Expressions.html[Bash Conditional Expressions].

== Упражнение 13: Топ расширений файлов

Используйте пайпы, чтобы найти 5 самых частых расширений файлов в домашней директории:

[,console]
----
$ find ~ -type f | sed 's/.*\.//' | sort | uniq -c | sort -rn | head -n5
----

Подсказка: комбинация `find`, `sed`/`awk`, `sort`, `uniq -c`, `head`.

== Упражнение 14: find и xargs

`xargs` преобразует строки stdin в аргументы команд.

Используйте `find` и `xargs` (не `find -exec`), чтобы найти все `.sh`-файлы в директории и подсчитать строки в каждом через `wc -l`:

[,console]
----
$ find . -name "*.sh" -print0 | xargs -0 wc -l
----

Бонус: `-print0` и `-0` корректно обрабатывают имена файлов с пробелами.

Подробнее: `man xargs`.
