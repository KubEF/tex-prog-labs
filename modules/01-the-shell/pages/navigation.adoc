= Навигация в оболочке

При запуске терминала вы видите *приглашение* (prompt):

[,console]
----
missing:~$
----

Это указывает, что вы находитесь на машине `missing`, а текущий рабочий каталог -- `~` (домашний каталог).
Знак `$` означает, что вы не root-пользователь.

== Запуск команд

Самая базовая команда -- запуск программы:

[,console]
----
missing:~$ date
Fri 10 Jan 2020 11:49:31 AM EST
----

Мы запустили программу `date`, которая выводит текущую дату и время.
Команда с *аргументами*:

[,console]
----
missing:~$ echo hello
hello
----

Оболочка разбивает команду по пробелам и запускает первую часть как программу, остальное передаёт как аргументы.
Для аргументов с пробелами используйте кавычки (`'` или `"`) или экранирование (`\`).

== Справка: man и --help

Важнейшая команда -- `man` (manual):

[,console]
----
missing:~$ man date
----

Она показывает подробную информацию о любой команде.
Короткую справку можно получить через `--help`:

[,console]
----
missing:~$ date --help
----

== Смена каталога: cd

Команда `cd` (change directory) -- встроена в оболочку (не отдельная программа).
Текущий каталог отражается в приглашении:

[,console]
----
missing:~$ cd /bin
missing:/bin$ cd /
missing:/$ cd ~
missing:~$
----

У оболочки есть автодополнение по `<TAB>`.

== Текущий каталог: pwd

Если не уверены, где находитесь:

[,console]
----
missing:~$ pwd
/home/missing
----

Или выведите переменную окружения:

[,console]
----
missing:~$ echo $PWD
/home/missing
----

== Относительные и абсолютные пути

Абсолютные пути начинаются с `/` и задают полный путь от корня файловой системы.
Относительные пути -- от текущего каталога:

[,console]
----
missing:~$ cd /
missing:/$ cd bin
missing:/bin$
----

Специальные компоненты:

* `.` -- текущий каталог
* `..` -- родительский каталог

[,console]
----
missing:~$ cd /
missing:/$ cd bin/../bin/../bin/././../bin/..
missing:/$
----
